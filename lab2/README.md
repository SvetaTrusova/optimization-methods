# Лабораторная работа №2. Метод ломаных

Трусова Светлана Викторовна, поток МетОпт 1.1.

Собственная реализация метода Пиявского для глобальной минимизации липшицевой функции на отрезке. Верхние вершины хранятся в отсортированном списке; нижние рассчитываются как пересечения лучей соседних верхних вершин.

## Запуск

Требуется Python 3.9+ и matplotlib:

```bash
pip install -r requirements.txt
python solver.py
```

Тест по умолчанию: срез Растригина `x**2 + 10*(1-cos(2*pi*x))`, отрезок [-2, 2], eps = 0.01, L = 70.

Другой пример (из занятия):

```bash
python solver.py --function "0.5*(x-2)**2 + sin(pi*x)" --a 0 --b 4 --eps 1 --L 6 --output lecture-result
```

На входе: формула строкой, a, b, eps и обоснованная константа L. Для другой функции L необходимо выбрать заново: программа не доказывает условие Липшица автоматически. По умолчанию L = 70 относится только к тесту Растригина.

В формулах доступны x, pi, e, sin, cos, tan, exp, log, sqrt, abs; степень записывается через **. Функция должна быть определена и липшицева на всём отрезке.

## Файлы

- `solver.py` - код программы.
- `requirements.txt` - зависимости.
- `report.pdf` - отчёт.
- `solver-result.png` - график функции, итоговая ломаная и найденная точка.
- `iterations.csv` - журнал внутренних итераций (две стартовые пробы не включены).
- `result.json` - параметры и результаты запуска.

Результат теста: x = 0, W = 0; 140 внутренних итераций, 142 вычисления функции. Останов: W последней пробы минус высота выбранной нижней вершины < eps. Ответ - лучшая вычисленная точка. Точность относится к значению функции, а не к координате x.

Сетка используется только для отрисовки графика. Поиск выполняется по пересечениям; scipy.optimize не используется. Время в result.json измеряется только для поиска, без построения рисунка и записи файлов, и зависит от компьютера.
