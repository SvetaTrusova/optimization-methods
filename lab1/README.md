**Вариант:** 7 (27 mod 20).

## Постановка

Максимизировать `Z = 3x1 + 2x2 + x3 + 4x4` при ограничениях:

- `2x1 + x2 + x3 <= 12`;
- `x2 + x3 + x4 = 9`;
- `x1 + x4 >= 4`;
- `x1, x2, x3, x4 >= 0`.

В работе принята постановка с неотрицательными исходными переменными.

## Выполнение

Задача приведена к каноническому виду и решена двухфазным симплекс-методом. Вспомогательная функция достигла нуля за две итерации. Основная задача потребовала ещё двух итераций. В Python реализованы вычисление приведённых коэффициентов, правило отношений и пересчёт таблиц. Готовые оптимизационные солверы не используются.

## Результат

`x* = (6; 0; 0; 9)`, `Zmax = 54`.

Ручное решение и запуск Python дали одинаковый результат. Допустимость проверена подстановкой. Оптимальность дополнительно подтверждается верхней границей `Z <= 54`.
